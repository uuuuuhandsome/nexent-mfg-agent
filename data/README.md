# 数据说明

## 原则

1. **真实优先**：能用公开真实数据的，不用编。标准条文、设备手册、传感器记录都优先找公开来源。
2. **合成必须声明**：凡是生成的模拟数据，文件名或文件头必须标注 `synthetic`，并在下表中登记。
3. **原始文档不入库**：手册、标准全文体积大且有版权，只放**片段**和**出处链接**。

## 目录约定

```
data/
├── raw/          # 原始文档（不入库，仅本地）
├── samples/      # 可公开的样例数据（几 MB 以内）
└── synthetic/    # 合成数据，文件名带 synthetic 前缀
```

## 版权与合规

- 国家标准（GB/GB-T）只引用**实际用到的条款片段**，不整本转载，注明标准号与条款号。
- 厂商手册只放**页面截图或片段**，并标注厂商与型号，不做二次分发。
- 涉及真实企业、真实人员的信息一律脱敏。
